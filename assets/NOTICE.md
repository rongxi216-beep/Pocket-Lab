Pocket Lab 道具、图标和 UI 由本项目脚本及 SVG 原创绘制；修改版背景 lab-room-v2.png 使用内置 image_gen 原创生成，提示词与用途见 docs/ART-V2.md。音效由反馈模块按材质合成，无远程运行时资源。

PocketLabUI-v3.ttf 是 Noto Sans SC Regular 的当前界面字形子集（Google Fonts text API 获取），SIL Open Font License 1.1，见 FONT-LICENSE.txt。PocketLabUI-v2.ttf 与 PocketLabUI.ttf 保留为旧版字体。字体离线随项目打包，不依赖设备安装字体；增加界面文案时需重新生成子集或使用完整 Noto Sans SC。
