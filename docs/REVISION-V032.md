# v0.3.2 · 只回退物理，保留属性栏试玩

按用户反馈撤回 v0.3.1 的物理手感调整。

- scripts/lab_body.gd 和 scripts/world.gd 从 v0.3 源码归档逐字节恢复。
- app.gd 的物理更新函数恢复 v0.3，包括木板原来的移动方式；保留其属性栏手势、目标切换、合并撤销改动。
- hud.gd、feedback.gd、device_motion.gd 与 v0.3.1 归档逐字节一致。
- 不清空存档、不更改保存的属性值。撤回的是运行规则；当前物体的位置/速度继续采用本地存档。
- 撤回新增空气阻力、接触滚动损耗、弹性折半映射、边界材质以及木板扫掠/推力。原版已有阻尼、弹性和速度限制保留。

基础回归、第二版回归、独立进程保存恢复和属性栏内拖动/切换/整轮撤销测试重新执行。新增衰减的验收条件已从当前测试移除，因为该功能已撤回；旧结果文件及 REVISION-V031.md 只代表历史版本，不代表当前物理。

下一阶段不继续增加物理公式：先保留此版本作为手感基线，再在独立的小测试场景中一次复现一种问题。先看单球落地，再看木板接触、滚动、弹簧，最后组合风扇等持续供能道具。一次只调一个因素，记录前后相同操作的画面，用户认可手感后才应用主场景。自动化测试负责发现穿透、速度异常和交互回归，不能替代手感验收。

木板仍是固定道具；自由刚体模式、现实单位标定、空气/滚动阻力均暂不新增。界面、背景、音效、手机轻动没有扩展。运行仍使用 Run-PocketLab.cmd；当前未生成 APK，未做 Android/iOS 真机验证。
