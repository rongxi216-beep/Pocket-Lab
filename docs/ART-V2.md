# 实验室美术修改版

原创背景 `assets/lab-room-v2.png` 由内置 image_gen 生成，非外部素材拼贴；道具和 UI 由项目程序化绘制，保持独立碰撞与触控。仅实现实验室主题，未来主题通过 scene theme 配置替换颜色和资源。

背景最终提示词：

Use case: stylized-concept. Asset type: finished background illustration for a playable portrait 2D cozy physics sandbox, NOT a UI mockup. Create an original charming modern miniature science laboratory in warm pastel cartoon illustration style with rounded toy-like architecture, soft matte shading and fine warm outlines. Portrait 2:3 composition, front-on cutaway view, no extreme perspective. A huge quiet pale ivory-mint back wall occupies center 70% width and middle 65% height, deliberately empty for separately rendered moving physics toys. Upper perimeter has a small round-corner window with blue sky, peach morning light, a compact shelf with pastel flasks and books, a small green plant, friendly small wall instruments, cream and mint wall panels. All detail stays at upper edge and far left/right perimeter; no objects obstruct the big center. Bottom 8% is a horizontal rounded cream laboratory benchtop with warm timber edge, simple teal lower cabinetry at very bottom. Modern yet homely, playful engineering workshop, healing gentle mood, cohesive muted mint green #75aa9c, cream #f6f2df, apricot #edb88b, powder blue #a6cbd0. Flat clearly readable illustration, restrained grain, soft daylight, beautiful intentional illustration design. No characters, no balls, no fans, no magnets, no springs, no loose foreground objects, no text, no typography, no UI buttons, no numbers, no logo, no watermark. Background should frame and support real game objects.
