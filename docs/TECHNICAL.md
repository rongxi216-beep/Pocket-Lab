# 产品与技术方案

当前 0.3.0 的交互与参数变更见 [REVISION-V3.md](REVISION-V3.md)，本页保留基础架构说明。

唯一场景 desktop，五种道具，打开即触摸；不引入账号、网络服务、商业系统或任务目标。使用 **Godot 4.6 stable Standard + GDScript + Compatibility renderer**。使用成熟内置二维物理，在 Windows 可验证，核心脚本可导出 Android/iOS。锁定版本避免物理结果随升级变化；这不代表 4.6 是最新版本。

## 物理与交互

- 固定 60 Hz，16 次求解器迭代，最多每帧追赶 8 步，渲染上限 60 FPS。Godot 插值负责刚体画面，弹簧端点使用前后物理变换与插值分数绘制。创建/复位重置插值。
- 层 1 为动态球，层 2 为固定道具及边界；球与两层相撞，固定物体之间不参与碰撞。球使用圆形 Shape Cast CCD；挡板为矩形；风扇、磁铁为固定圆形，轮廓是玩具式近似。
- 重力 650 px/s²；球半径 17、质量 1、弹性 0.66、摩擦 0.38。边界四个静态矩形。平动、角动量、滚动、摩擦交给 Godot。
- 拖球使用质量归一化伺服：加速度 `105*(target-position)-20.5*velocity`，限幅 9500 px/s²。释放保留当前物理速度并限为 850 px/s，不从稀疏触点差分制造抛速。单指占有手势，额外手指忽略，取消/后台解除持有。
- 固定道具为 frozen kinematic RigidBody2D，在物理步内最多 650 px/s 移向触点。暂停时球采用相同限速摆放。0.3 旋转改为长按面板的方向滑块，旋转前检查碰撞与边界；尺寸调整检查当前位置空间，不自动搬动物体。高密度固定物体移动仍需真机挤压测试。
- 弹簧力 `F=k*(distance-rest)+damping*relative_axial_velocity`，两端反向；超过自然长 2.5 倍时加渐进阻力，单连接限幅 4500。这是有限力柔性约束，没有硬长度锁。支持球—球、球—固定物体、球—空白锚点，拒绝同端点、重复、悬空 ID、全固定连接。
- 磁力在 155 px 内按 `(1-distance/range)^1.35` 衰减；多场自然合力。风向跟随风扇旋转，只在前方渐宽风区作用，按前向距离与横向偏移衰减。力场合力上限 5000；球速度上限 1100、角速度 35 rad/s。
- 上限 48 球、28 固定道具、48 弹簧。只遍历球与场源，先范围判定，复杂度 O(B×F+S)，最多 1344 对。当前不引入空间树，提升上限后再加 Area2D 或空间哈希。静止球允许休眠，活跃力场/弹簧唤醒受力球。
- 碰撞波纹最多 16，短音最多同时 4 个，另有一个共享风声循环，全局 75 ms 短音冷却。没有大量粒子节点或实时灯光。默认静音，振动支持独立开关；平台不支持则无效果而不阻断操作。

## 编辑、保存、生成

添加、删除、移动、旋转、复制、复位、连接、断开、清空、打开作品、重新组合前保存快照，内存撤销深度 24。快照含那一刻的运动状态。复制单个道具不复制关联弹簧，以免改变原结构。撤销不跨进程保存；独立 previous 快照跨重启有效。

每 2 秒自动保存，结构操作结束立即保存；后台、失焦和正常关闭保存。拖拽中周期保存延后，后台仍保存并解除拖拽。后台冻结物理、停音源、渲染上限降至 10，前台恢复原暂停状态。系统硬杀无法保证回调，一般损失至多最近 2 秒；长拖拽中硬杀可能损失从拖拽开始以来的移动。

`user://` 下：session.json、settings.json、previous.json、works.json。先写临时文件并 flush，保留前一个主文件为 .bak，再替换。读取主文件缺失/损坏则回退备份。检查未知 schema、无效数值、悬空连接、容量上限。不能承诺硬件断电时绝对不丢数据，未实现数据库级 fsync 事务。

version=1 包含场景标识、道具 ID/类型/位置/角度/速度/角速度/初始状态/属性，弹簧端点 ID 与坐标、自然长、刚度、阻尼，旧桌面尺寸和暂停状态。还原先建立完整图，再进入下一物理步，限制速度。不同屏幕按旧边界比例映射位置和锚点；大幅缩屏可能压紧结构，目前依靠碰撞求解和限速恢复。

生成器从 5 个模板选择，对位置/角度做小幅扰动，使用保守包围圆检查穿插，80 次以内寻找间距。种子保存在会话、作品和快照。重新组合先落盘 previous，失败则取消组合。测试覆盖 450 个种子/尺寸组合，无严重重叠或非法连接。

## 扩展及技术风险

已有 pack_id/scene_id 和独立 item 定义。新力场可通过 providers 注册；新道具仍需添加形状/外观工厂分支，无需编写新旧道具组合配方。未来场景可提供环境参数和视觉配置；当前只装载 desktop，不包含任意内容包热加载、购买系统。迁移入口在 Storage 校验及 World.restore，当前未知版本安全回退，不虚构未来版本的迁移。

剩余风险：移动 GPU/温控与音频延迟、固定物体快速挤压、极端连接密度、缩屏重叠、真实后台终止时机、各机型震动差异。合成音效可用，音色和触觉仍需真机调校。自绘 HUD 尚无完整屏幕阅读器语义、大字模式；本地作品上限 40，尚无重命名/删除管理。普通手机 60 FPS 是目标，尚非本次测得结论。
