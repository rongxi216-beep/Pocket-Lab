# v0.3.1 · 属性栏内试玩与能量衰减

## 本次完成

- 属性面板只拦截自己的触摸区域，画布可继续拖动、抛出。一次手势由开始区域持有，拖进面板不会误触滑块。保持单指所有权，不支持两根手指同时操作两个控件。
- 拖动别的道具不会改变正在编辑的目标；长按另一道具才结束上一轮编辑并切换。每轮参数和试拖操作共用一个撤销快照，还原本次也恢复整个场景。
- 木板保持固定道具，移动时每秒最多 360 逻辑像素，使用引擎 move_and_collide 扫掠碰撞。碰到小球时停在接触处，并在运行状态施加有限推力；堵住的球不会被木板直接穿透。固定木板不会因球撞击自行倒下，本次未加入自由刚体木板。
- 修正材质弹性叠加：每颗球提供滑块值的一半（最大 0.45），木板贡献 0.08、其他固定道具 0.12、外边界 0.15；两颗最大弹性球合计不超过 0.9。原存档和滑块值保持，但采用新的材质映射。
- 增加速度相关空气阻力，按速度、半径平方与质量计算指数衰减；更大迎风面积阻力更明显，同尺寸较重物体受空气影响较小。保持重力加速度与质量无关。
- 在接近稳定的固定表面接触中增加切向与角速度阻尼，减少平地无限滚动。空中不施加接触滚动阻尼；现有弹簧阻尼保留。
- scripts/feedback.gd 与 v0.3 源码包逐字节比对一致，声音和音乐未修改。

## 参数与物理范围

重力仍为 650 px/s²，空气速度衰减率为 `(0.10 + 0.00014 * speed) * (radius / 17)² / mass`，每物理步乘 `exp(-rate * dt)`，避免阻力反向加速。滚动近似阻尼率为 `0.25 + friction * 0.8`，只作用于法向速度较小的支撑接触。这是有明确耗散规律的玩具尺度近似，未标定为真实空气密度、真实球体材质或 SI 单位实验仪器。

Godot 的两个材质弹性贡献相加，参见 [官方 PhysicsMaterial 文档](https://docs.godotengine.org/en/stable/classes/class_physicsmaterial.html)。空气阻力、碰撞损失、接触损失分别处理，不为特定道具组合播放动画。风扇、手指推拉持续供能时仍可持续运动。

## 验证

完整基础回归 8282 项、第二版回归 157 项均为零失败；跨进程保存恢复通过。新增 tests/interaction_physics_suite.gd 覆盖：

- 实际 Viewport 触控下，暂停/运行时保持面板拖动物体、释放、目标锁定、长按切换和整轮撤销。
- 无风力场自由落球，连续反弹高度下降并最终停稳。
- 平地滚动 3 秒后减速；最大弹性双球碰撞仍损失动能。
- 弹簧摆动后期摆幅低于早期；移动木板向顶部挤球时保持有限速度及边界。

具体数值保存于 tests/interaction-physics-results.json。物理更新与接触采样存在离散误差，测试不代表所有复杂搭建都不会穿透。快速变形、既有重叠结构和移动挡板推力手感仍可继续调优。

运行方式不变，双击 Run-PocketLab.cmd。源码与 PCK 在 builds/PocketLab-v0.3.1-*；PCK 需要 Godot 4.6 引擎，不是独立安装包。当前仍无 Android APK 或 Android/iOS 真机测试。
