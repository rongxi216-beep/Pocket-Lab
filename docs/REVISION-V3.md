# 第二版初步开发 · v0.3.0

这一轮聚焦随手把玩的交互，沿用晨光实验室美术及五种道具，不增加场景或系统。

## 交互与画面

普通点选不出现浮动操作栏，不显示旋转把手。静止长按 0.48 秒进入属性；超过拖动阈值后，本次手势不再触发长按。工具抽屉默认收起，首次无存档为一颗较大的弹簧小球和木板；既有存档保留。

底部属性面板高 244 个逻辑像素，另加设备底部安全区。每次只显示一个参数滑块，通过标签切换；模拟继续运行，可主动暂停。重量和大小独立调整。复制、复位、删除和方向调节只在长按面板出现。收起或下滑把手保留修改；还原本次恢复整个进入编辑前的快照，包括运动状态。参数编辑直到关闭才合并进一次撤销记录；删除/复制本身仍各有一条结构撤销。

实验区从顶部 76 像素以下延伸至底部抽屉上沿，背景书架和窗户无碰撞体。打开抽屉或属性面板，通过 Viewport canvas_transform 把完整世界等比适配到剩余区域，物理边界和物体坐标不变。输入使用逆变换换算，HUD 使用独立 CanvasLayer。真正的窗口尺寸改变才重新映射世界。

几何参数在当前位置用引擎形状查询检测边界和重叠，放不下则拒绝本次值并提示；不自动瞬移让位。当前方向滑块也执行目标形状查询，但不是完整的旋转扫掠碰撞求解。较密的结构仍建议暂停后调整。

## 物理与手机运动

现有 60 Hz 刚体、弹簧、磁力、风力及速度限制保持。参数直接更新真实质量、碰撞形状、材质及力场；同等风力下质量越大，加速度越小。

新增 scripts/device_motion.gd，把设备重力/加速度读数映射为附加加速度和轻晃冲量。启用 Android 的 gravity 与 accelerometer 项目开关；不要求陀螺仪。首次采样以当前握持姿态校准，0.28 秒低通，0.45 m/s² 死区，最大附加加速度 120 px/s²。轻晃阈值 4.5 m/s²，最大速度增量 45 px/s，冷却 0.9 秒，校准后等待 1 秒。没有独立重力读数时采用加速度低通且停用晃动检测；没有读数则纯触摸运行。

力乘以球质量作为一致的惯性加速度；固定道具不会被摇走。打开面板、拖动、暂停及切后台均抑制并重置滤波；恢复重新校准，避免旧读数突跳。设置“随手机轻动”本地保存。地铁启动、刹车与人的晃动不能完全区分，当前优先保守幅度。

API 依据：[Godot Input 官方文档](https://docs.godotengine.org/en/stable/classes/class_input.html#class-input-method-get-gravity)。本次未在手机测量传感器轴向和灵敏度，Android/iOS 真机必须分别验证。

## 声音

关闭风扇循环声；长按和 UI 操作无通用音效。开启声音时仅播放金属、木质、塑料的短碰撞声，低于 0.18 强度不播放，间隔至少 140 ms，4 声部池，音量 -38 至 -24 dB。触觉独立保留。现有声音为程序合成的原型素材，尚未达到专业录音质量，音色与真实手机扬声器响度待调校。

## 验证与交付

Godot 4.6 Windows 脚本导入与实际画面捕获；基础测试 8282 项、第二版测试 157 项均通过。tests/revision_suite.gd 使用 Viewport 触摸事件及合成传感器读数，包含不同质量的真实风场运动比较、下滑关闭、后台恢复、不同高度的画布可见性。独立进程重启保存读写另由 tests/restart.gd 覆盖。截图见 properties-v3.png、preview-v3.png、settings-v3.png、short-screen-v3.png、tall-screen-v3.png。

源码包和 PCK 资源包位于 builds，PCK 需 Godot 引擎运行，不是独立安装包。未生成 APK；当前缺 Android SDK、JDK、导出模板和连接的手机。导出步骤见 MOBILE.md。

## 后续真机验收重点

- 单手长按、面板下滑、刘海与底部手势区；800/1000 高度已做桌面模拟，真实安全区尚未验证。
- 竖屏左右倾斜方向，平放/站立握持校准，走路/乘车误触幅度，切后台后无突然冲量。
- 普通 Android 手机 48 球时的帧率、温升与电耗；桌面回归不证明手机性能。
- 调大贴地或互相挤压的球会拒绝增长，应先拉开空间；不提供自动搬物体。
- 画布目前立即等比适配，没有过渡动画；小尺寸物体随画布缩放，后续可评估选中物附近的局部取景。
- 作品管理、完整无障碍、真实材质录音、水中行为均不在本轮交付范围。
